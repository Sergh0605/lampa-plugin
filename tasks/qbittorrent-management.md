# Управление торрентами qBittorrent из плагина Lampa

## Цель

Из списка торрентов в Lampa: ставить торрент на закачку в qBittorrent с выбором
категории, видеть живой статус цветом + прогресс, управлять (стоп/старт/удалить с файлами).
Всё — удобно с пульта ТВ.

## Контекст инфры

- qBittorrent: `http://192.168.1.1:8192/qbittorrent/*` (nginx `media-server` → `192.168.1.41:8080`), Basic `admin:<пароль в DEFAULTS>`.
- В qBittorrent подключен Jackett (поиск), Jackett подключен к Lampa как парсер.
  Раздачи в Lampa приходят из поиска Jackett → `element.Guid` в событии `render` = URL страницы
  (совпадает с полем `comment` у торрентов клиента). Категории клиента: «Фильмы», «Сериалы», «Софт».
- Тест: Lampa `http://192.168.1.1:9100`, плагин `http://192.168.1.1:8192/lampa-test/<name>.js`,
  логи `logs/lampa-plugin.log` ← POST `http://192.168.1.1:9101/log`.

## Зафиксированные решения

- Удаление — всегда с файлами (`deleteFiles=true`), один пункт + подтверждение через Modal.
- Вход в меню — контекстное меню торрента (долгое нажатие `hover:long` на строке `item`).
- Категории при закачке — только «Фильмы» / «Сериалы» (фильтр списка клиента).
- Бейдж строки: цвет статуса + прогресс-бар + `%` + скорость + ETA.
- Обновление: при загрузке страницы + опрос `info` раз в 10 с (один `silent`-запрос),
  плюс сразу после каждого действия. Холостой опрос в лог не пишем.

## Статус → цвет

- 🟡 качается: `downloading, metadl, stalledDL, checkingDL, allocating, queuedDL, forcedDL, checkingResumeData, moving`
- 🟢 раздаётся: `uploading, stalledUP, checkingUP, queuedUP, forcedUP`
- 🔵 скачан, остановлен: `pausedUP` / `stoppedUP` (progress = 1)
- 🔴 не докачан, остановлен: `pausedDL` / `stoppedDL`, `error`, `missingFiles`, `unknown`

## Меню (`Lampa.Select.show`, вертикально, пульт: вверх/вниз/ОК/Назад)

- Новый торрент: шапка имя/размер; пункты «⬇ Скачать в „Фильмы"» / «⬇ Скачать в „Сериалы"»
  (последняя использованная — первой, храним в `Storage`), клик = сразу закачка.
- Существующий: шапка-инфо (имя, статус словами, %, скорость, ETA) + «↻ Обновить статус»;
  пункты: «⏸ Остановить» / «▶ Продолжить», «🗑 Удалить с файлами» (confirm-Modal), Назад — кнопкой пульта.
- Тосты `Noty` на результат + ошибки в лог (`add/pause/delete ok/fail`).

## API qBittorrent (v2, POST, `hashes=` / `urls=` + `category=`)

- `POST /torrents/add` (`urls=<magnet|url>&category=Фильмы|Сериалы`)
- `POST /torrents/stop|start` (`hashes=<hash>`; в v5.x НЕ `pause`/`resume`)
- `POST /torrents/delete` (`hashes=<hash>&deleteFiles=true`)
- `GET /torrents/info`, `GET /torrents/categories`

## Тест вручную

Сборка → `lampa-test/` → `curl 200` → Ctrl+F5 → список торрентов →
долгое нажатие → меню → действия на реальном клиенте
(для «удалить с файлами» — заранее выбрать жертвенный торрент).
`__BUILD__` в логи; холостой опрос в лог не пишем, только смены состояний/действия/ошибки.
